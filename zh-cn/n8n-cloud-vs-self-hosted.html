工作流程频率检查

简单的计划如何使用云执行津贴

考虑一个工作流程，该工作流程在每月第 30 天的时间内按五分钟的计划运行。如果每个计划运行都完成并算作一次执行，即 12 每小时运行 × 24 小时 × 30 天 = 8,640 执行次数。这超出了 2,500-执行入门限额，即使它只是一个工作流程。在云上，检查计划的当前配额以及 n8n 如何计算执行次数；在 VPS 上，检查真实的服务器负载和资源使用情况，而不是将执行计数视为容量。

说明性算术，不是性能基准或使用预测。作为 Webhook 运行而不是轮询，工作负载可能会更便宜，但请根据您的实际集成要求选择触发器。验证官方 n8n 云配额。

第三种运营模式

一键式 n8n VPS 并不总是一项托管服务

除了官方 n8n 云和运营您自己的 VPS 之外，一些公司还销售预安装或托管的 n8n 托管。这些是单独的商业产品，具有不同的支持、备份和软件更新责任。一键安装简化了设置，但并不能证明提供商管理 n8n 应用程序。如果您比较第三方产品，请检查确切的服务协议、备份保留、执行限制和许可；它并不自动等同于官方 n8n 云。

实际成本模型

示例：自托管 n8n 月的实际费用是多少？

作为说明，自我管理的 Standard VPS 的定价为 每天 $0.07 成本 $2.10 为 30 计费天数 在附加组件之前。更大的 每天 $0.67 选择成本 $20.10 为 30 计费天数。这些是服务器费用，而不是全部应用程序成本。根据实际工作负载而不是此示例选择服务器大小。

每月自托管 TCO = VPS 费用 + 付费备份/存储/监控 + 外部服务 + 管理员时间。

插图： $20.10 VPS + $5 选定的经常性额外费用 + 两个管理员时间，价值为 $20/小时 = 该月的 $65.10.

替代方案： $2.10 VPS + 无选定的付费额外服务 + 零单独收费的管理员时间 = $2.10 直接服务器费用，但并不免除维护或恢复责任。

$5 额外费用、两小时和 $20/小时是假设输入，而不是提供商报价或对您实际工作量的预测。按 $20/小时计算，每增加一小时管理，自托管 TCO 就会改变 $20；不能仅仅因为没有提供商发票就认为一小时是免费的。要找到盈亏平衡点，请将实际涵盖已完成执行、并发性和所需功能的云层与 VPS + 额外内容 + 时间（按您自己的费率计算）进行比较。检查当前的云账单。付费 n8n 自托管版本需要单独的许可证。

版本和许可边界

托管模型和 n8n 版本是单独决定的

n8n 云

云层将托管托管与特定的执行限额、并发性、保留和协作功能捆绑在一起。官方年度计费 Starter 示例包括 2,500 执行/月和 5 并发执行； Pro 列出了每月 10,000 执行次数，具有更多并发性和项目功能。精确的计划和合同条款很重要：选择涵盖峰值并行运行和每月完成执行的层级。查看官方云矩阵。

自托管社区

在您自己的 VPS 上运行 n8n 并不能解锁所有付费功能。社区版提供核心工作流程自动化，但不会自动授予付费协作、治理、支持、源代码控制或企业功能。在为团队选择计划之前，请检查官方版本的功能矩阵。

自托管商业/企业

许可证密钥可解锁付费的自托管功能。即使软件版本已付费，基础设施仍然由您来运行。

为其他用户托管 n8n

如果组织外部的人员可以在您提供的 n8n 实例上构建或配置工作流程，请勿假设免费的自托管许可证涵盖该服务模型。在将 n8n 作为托管产品提供之前，请检查 n8n 的当前许可规则。

常见问题

n8n 云与自托管：常见问题

n8n 云比自托管更好吗？

不具有普遍性。当托管基础设施和低运营开销主导决策时，云会更好。当基础设施控制和自定义部署要求证明您可以自行操作堆栈时，自托管会更好。

自托管 n8n 便宜吗？

原始 VPS 费用可能比云订阅低得多，但这并不能证明总成本较低。添加备份、监控、维护、管理员时间和任何付费版本功能。与 Cloud 当前的执行限额和计划限制进行比较。有关明确的计算，请参阅上面的成本示例。

自托管 n8n 可以在生产环境中运行吗？

是的。生产准备情况取决于部署的质量：数据库、持久性、HTTPS、安全性、监控、备份和恢复程序都很重要。

自托管 n8n 是否需要 Redis？

否。Redis 与队列模式和分布式工作人员相关。默认情况下，正常的单实例 VPS 不需要 Redis。

我什么时候应该选择 VPS？

当服务器级控制、专用网络、数据位置控制或自我管理扩展足够重要以证明拥有更新、安全性、监控和恢复的合理性时，请选择 VPS。 VPS 的价格本身并不能确定自托管是否更便宜。

n8n 云算什么执行？

n8n 云定价基于已完成的工作流执行，而不是一次执行中的单个节点或步骤。比较您所需的云层已发布的每月执行限额和并发执行限制。

我可以从 n8n 云迁移到自托管吗？

计划导出工作流程并评估凭证、加密密钥、执行历史记录、用户、Webhook URL 和触发器计划的传输方式。工作流导出与完整数据库还原不同。在退出旧环境之前测试导入和割接；看到 备份和恢复指南.

长期运营

这种部署可以保持多年的可靠性吗？

官方 n8n 云和自托管 VPS 都不能真实保证特定工作流程将不间断运行十年。对于业务关键型自动化，询问适用哪些服务条款和支持承诺、如何检测事件、谁恢复实例以及当您的部署或其外部 API 失败时会发生什么。

对于官方 n8n 云

确认服务层已发布的支持条款、数据导出功能和事件流程。托管基础设施减少了服务器管理，但并没有消除监控业务成果和集成故障的需要。

对于自托管 VPS

指定安全补丁、监控和升级的所有者；保留独立备份并在新主机上测试恢复。考虑如何在 VPS、磁盘、区域或第三方集成失败时进行恢复，而不是将每月较低的服务器价格视为可靠性保证。

可用性、支持和恢复目标应基于记录的服务条款和您自己测试的程序，而不是未经验证的正常运行时间承诺。
