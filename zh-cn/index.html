购买问题的解答

VPS 对应 n8n：常见问题

小型企业应该选择哪种配置？

选择 2 vCPU、4 GB RAM 和 80 GB Standard 配置，以实现适度的 n8n 和 PostgreSQL 堆栈处理 CRM 更新、潜在客户和基于 JSON 的小型集成。对于数据量大的工作和大量重叠，使用更大的选项；对于小型且大多是连续作业的精益实例，请使用较轻的选项。

什么时候 8 GB RAM 比 4 GB 更好？

当您的工作流程在内存中保存较大的文件或数据集、执行较繁重的转换或同时运行多个要求较高的作业时。仅每月执行计数较高并不是将 RAM 加倍的理由；检查工作数据和峰值重叠。

AI 工作流程是否需要 GPU VPS？

调用托管模型 API 使用模型提供者的推理硬件。选择您的 n8n VPS 进行编排、有效负载和并发性。运行本地模型或单独的推理服务是不同的购买，具有特定于模型的 RAM 和硬件需求。

我选择 VPS 后会发生什么？

在托管目录中选择 Standard 服务器配置和 Linux 操作系统。将 n8n 与 Docker 一起部署，连接 HTTPS，然后添加您的工作流程凭据。此页面上的部署路径是自我管理的。 打开设置清单.

我可以将现有的工作流程移至此设置吗？

导出和导入工作流程，在需要时重新连接凭据，并有意切换 Webhook 和计划触发器。对于完整实例移动，请保留数据库和原始加密密钥，以便保存的凭据仍然可用。 迁移和恢复准备.

我需要 Redis 或付费控制面板吗？

常规单实例 Docker 部署可以在没有 Redis 或付费托管面板的情况下运行。当您需要基于工作线程的执行时，添加带有队列模式的 Redis；仅当其管理功能对您有用时才选择面板。

如何在不缩小服务器规模的情况下保持较低的 n8n VPS 成本？

从适合您的实际有效负载和峰值重叠的最小配置开始，然后在升级之前减少可避免的需求。修剪不需要的执行历史记录、批量导入、错开繁重的计划以及在不需要本地推理时使用托管 AI API。在最繁忙的时期测量内存、CPU 和磁盘；当优化的工作负载仍达到持续限制时，升级。
