CRITERIOS DE ELECCIÓN

Cómo elegir un VPS para n8n sin pagar de más

No elijas por número de workflows. La carga depende de cuántas ejecuciones coinciden, cuánto dato procesa cada una y qué servicios corren junto a n8n.

Concurrencia real

Varias ejecuciones simultáneas consumen más memoria y CPU que muchos workflows que corren en horarios distintos.

Instalación

Una plantilla preinstalada ahorra tiempo; Docker manual da más control. En ambos casos necesitas persistencia, HTTPS y una estrategia de actualización.

Gestionado o no gestionado

Un VPS no gestionado suele ser más barato, pero tú administras Linux, Docker, seguridad, copias y recuperación.

Ubicación y red

Prioriza latencia hacia las APIs y servicios que usa tu automatización, además de tráfico, estabilidad y capacidad de crecer.

PREGUNTAS FRECUENTES

Preguntas sobre VPS para n8n

¿Cuánta RAM necesita n8n?

2 GB pueden servir para una carga ligera. 4 GB es una base práctica cuando n8n comparte servidor con PostgreSQL y Docker. Para archivos grandes, IA o mucha concurrencia, 8 GB o más da margen adicional.

¿Necesito Redis?

No para una instancia normal. Redis entra en juego cuando escalas con modo cola y varios procesos worker.

¿Puede n8n ejecutarse con Docker?

Sí. Docker o Docker Compose con almacenamiento persistente, PostgreSQL y un proxy inverso es una arquitectura habitual para producción.

¿Necesito un dominio?

Para una URL HTTPS estable y webhooks públicos fiables, usa un dominio o subdominio apuntado al VPS.

¿Un VPS limita el número de ejecuciones?

El VPS no suele cobrar por ejecución: el límite práctico lo marcan CPU, RAM, almacenamiento y la arquitectura desplegada. Si la carga crece, optimiza y después amplía recursos o escala con workers.

¿Conviene n8n preinstalado o instalarlo manualmente?

Una plantilla preinstalada reduce el tiempo de puesta en marcha. La instalación manual con Docker ofrece más control. En ambos casos siguen importando backups, actualizaciones, seguridad y monitorización.
