ЛИМИТЫ И ВЫПОЛНЕНИЯ

VPS не считает executions — предел задают ресурсы

Нет тарифа «за выполнение»

Вы платите за серверные ресурсы. Практический предел n8n определяется памятью, CPU, диском, базой и архитектурой.

Параллельность важнее числа workflows

Десятки простых процессов по расписанию могут потреблять меньше ресурсов, чем несколько тяжёлых задач, стартующих одновременно.

История тоже стоит ресурсов

PostgreSQL, execution history, логи и бинарные данные увеличивают объём диска и I/O даже при умеренном числе workflows.

Лицензия n8n — отдельный вопрос

Самостоятельный хостинг Community Edition и платные Business/Enterprise-функции — разные уровни продукта; VPS не добавляет платные функции автоматически.

СНАЧАЛА ОПТИМИЗАЦИЯ

Когда не нужно сразу покупать больше RAM

История выполнений

Ограничьте retention и не храните успешные executions дольше, чем нужно для диагностики.

Расписание

Разведите тяжёлые задания по времени, если они не обязаны выполняться одновременно.

Данные

Не передавайте между узлами крупные JSON и бинарные данные без необходимости.

Метрики

Смотрите на RAM, CPU, рост диска и длительность выполнения и увеличивайте именно тот ресурс, который стал узким местом.

FAQ

Частые вопросы про VPS для n8n

Сколько RAM нужно для n8n?

1–2 GB достаточно для тестов и лёгких сценариев. Для небольшого production с PostgreSQL практичнее 4 GB. При тяжёлых данных, AI и высокой параллельности ориентируйтесь на 8 GB и выше.

Есть ли лимит на количество executions?

У VPS нет отдельного счётчика запусков n8n: предел задают ресурсы сервера и архитектура. При этом коммерческие редакции n8n могут иметь собственные лицензионные условия.

n8n будет уже установлен?

Эта страница исходит из самостоятельной установки n8n на VPS. Используйте Docker Compose и отдельную инструкцию на сайте; не рассчитывайте на предустановку, если она явно не заявлена провайдером.

Нужен ли домен?

Для стабильного HTTPS-адреса и внешних webhook лучше использовать домен или поддомен, направленный на VPS.

Нужен ли Redis?

Нет для обычного режима. Redis нужен при переходе на queue mode с workers.

Можно ли держать PostgreSQL и n8n на одном VPS?

Да для небольшого production, если оставить запас по RAM и диску. При росте нагрузки базу можно вынести отдельно.
