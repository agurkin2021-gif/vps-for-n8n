Production deployment order

Ubuntu/Debian VPS तैयार करें, Docker/Compose install करें, PostgreSQL और persistent volumes configure करें, फिर domain DNS और HTTPS reverse proxy जोड़ें।

Production में मुख्य बातें

Server → Docker → PostgreSQL → n8n environment → persistent storage → domain/DNS → HTTPS/reverse proxy → webhook test → backup. Default ports को बिना जरूरत public न रखें।

Production में मुख्य बातें

Deploy के बाद webhook URL, HTTPS renewal, persistent volumes और backup/restore verify करें। Self-hosted server/network/performance problems n8n Cloud की managed infrastructure support के बराबर नहीं होते।

मुख्य technical decisions

Production से पहले deployment verify करें

1

Docker Compose में n8n और PostgreSQL के persistent volumes रखें और PostgreSQL को public internet पर expose न करें।

2

N8N_ENCRYPTION_KEY स्थिर रखें और container से बाहर सुरक्षित करें।

3

Start के बाद docker compose ps, logs और /healthz जाँचें, फिर production webhooks चालू करें।

4

n8n version pin करें; PostgreSQL major version को उसी volume पर blind upgrade न करें।

क्या 1 GB वास्तविक VPS है?

हाँ। यह हल्के workload के लिए वास्तविक entry VPS है; सीमा केवल कम resource headroom है।

2 GB क्यों बेहतर light baseline है?

Docker, OS और छोटे peaks के लिए अधिक headroom मिलता है।

Scale से पहले measurement क्यों?
