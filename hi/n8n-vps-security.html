VPS विकल्प देखें

Credentials और access

Public production instance को HTTPS/reverse proxy के पीछे रखें, firewall से ports सीमित करें, SSH keys उपयोग करें और Docker/n8n/OS updates नियमित रखें।

Production में मुख्य बातें

Secrets को source code में न रखें। Admin access सीमित रखें, logs monitor करें और backups को server से अलग सुरक्षित रखें।

Production में मुख्य बातें

HTTPS और firewall के साथ public API तथा अनावश्यक nodes को restrict करें, execution data में sensitive input/output को redact करें और credentials/data-at-rest encryption की जिम्मेदारी स्पष्ट रखें।

मुख्य technical decisions

Host और n8n दोनों harden करें

1

HTTPS, restrictive firewall और SSH keys host को सुरक्षित करते हैं; PostgreSQL और Redis private रखें।

2

MFA/2FA enable करें और editor/admin rights को least privilege पर रखें।

3

Unused Public API और high-risk nodes restrict करें; community nodes को third-party code मानें।

4

SSRF protection और proper secret handling internal targets और credential leaks का risk घटाते हैं।
