Restore test क्यों जरूरी है

सिर्फ workflow export पर्याप्त नहीं। PostgreSQL/database, persistent volumes/config और encryption key का off-server backup रखें।

Production में मुख्य बातें

Backup तभी उपयोगी है जब restore काम करे। नियमित test restore करें और encryption key खोने से credentials unreadable होने के जोखिम को रोकें।

Production में मुख्य बातें

Database और volumes के साथ N8N_ENCRYPTION_KEY को सुरक्षित रखें। नई instance या migration में वही key न होने पर encrypted credentials restore होकर भी पढ़े नहीं जा सकते। नियमित test restore करें।

मुख्य technical decisions

Restore योग्य backup बनाएं

1

Database, N8N_ENCRYPTION_KEY, .n8n data और binary data को एक recovery set की तरह backup करें।

2

Workflow/credential export full instance backup नहीं है; users, roles, history, variables और settings छूट सकते हैं।

3

Restore पर owner/project assignment, ID collisions और workflow activation state verify करें।

4

RPO/RTO तय करें, off-server copy रखें और isolated environment में restore drill करें।
