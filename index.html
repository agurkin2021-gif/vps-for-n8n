FAQ

How much RAM does n8n need?

There is no universal number. 2 GB can suit lightweight workloads; 4 GB is a practical small-production baseline; heavier and AI workloads often need 8 GB or more.

Does n8n need Redis?

Not in regular mode. Redis becomes relevant when using queue mode with workers.

Can n8n run in Docker?

Yes. Docker Compose is a practical production deployment model with PostgreSQL and a reverse proxy.
