購買問題的解答

VPS 對應 n8n：常見問題

小型企業應該選擇哪種配置？

選擇 2 vCPU、4 GB RAM 和 80 GB Standard 配置，以實現適度的 n8n 和 PostgreSQL 堆疊處理 CRM 更新、潛在客戶和基於 JSON 的小型整合。對於資料量大的工作和大量重疊，使用更大的選項；對於小型且大多是連續作業的精實實例，請使用較輕的選項。

什麼時候 8 GB RAM 比 4 GB 更好？

當您的工作流程在記憶體中保存較大的檔案或資料集、執行較繁重的轉換或同時執行多個要求較高的作業時。僅每月執行次數較高並不是將 RAM 加倍的理由；檢查工作數據和高峰重疊。

AI 工作流程是否需要 GPU VPS？

呼叫託管模型 API 使用模型提供者的推理硬體。選擇您的 n8n VPS 進行編排、有效負載和並發性。運行本地模型或單獨的推理服務是不同的購買，具有特定於模型的 RAM 和硬體需求。

我選擇 VPS 後會發生什麼事？

在託管目錄中選擇 Standard 伺服器設定和 Linux 作業系統。將 n8n 與 Docker 一起部署，連接 HTTPS，然後新增您的工作流程憑證。此頁面上的部署路徑是自我管理的。 開啟設定清單.

我可以將現有的工作流程移至此設定嗎？

匯出和匯入工作流程，在需要時重新連接憑證，並有意切換 Webhook 和計劃觸發器。對於完整實例移動，請保留資料庫和原始加密金鑰，以便保存的憑證仍然可用。 遷移和恢復準備.

我需要 Redis 或付費控制面板嗎？

常規單一實例 Docker 部署可以在沒有 Redis 或付費託管面板的情況下運作。當您需要基於工作執行緒的執行時，新增具有佇列模式的 Redis；僅當其管理功能對您有用時才選擇面板。

如何在不縮小伺服器規模的情況下保持較低的 n8n VPS 成本？

從適合您的實際有效負載和尖峰重疊的最小配置開始，然後在升級之前減少可避免的需求。修剪不需要的執行歷史記錄、批次匯入、錯開繁重的計劃以及在不需要本地推理時使用託管 AI API。在最繁忙的時期測量記憶體、CPU 和磁碟；當最佳化的工作負載仍達到持續限制時，升級。
