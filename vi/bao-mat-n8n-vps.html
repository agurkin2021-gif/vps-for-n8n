Bảo mật n8n VPS

SERP Việt Nam chủ yếu có bài gắn domain/SSL hoặc VPS tổng quan. Production security cần bảo vệ cả host, n8n, workflow execution và secrets.

HOST + APP SECURITY

SSL là baseline, không phải toàn bộ bảo mật

HTTPSPublic editor/webhook phải dùng TLS; theo dõi certificate renewal.
SSH + firewallKey-based SSH, mở ít port; PostgreSQL/Redis giữ private.
MFA / rolesBật MFA/2FA nếu edition hỗ trợ và dùng least privilege cho admin/editor.
API / nodesTắt hoặc giới hạn Public API/node có rủi ro nếu không dùng.
SSRF / networkGiới hạn khả năng workflow chạm metadata/internal services; app protection chỉ là defense-in-depth.
SecretsEncryption key, DB password và API key không được leak qua repo/log/backup không bảo vệ.

Attack surface nằm cả bên trong workflow

Community nodes

Coi như third-party code; kiểm tra nguồn, version và quyền.

Code nodes

Arbitrary code làm tăng blast radius; hạn chế người có quyền chỉnh sửa.

Execution history

Payload nhạy cảm có thể nằm trong history/log; đặt retention phù hợp.

Backups

Backup chứa dữ liệu/credentials cần encryption và access control riêng.

Patch cadence

OS, Docker, n8n và dependency phải có lịch update + rollback.

Incident plan

Biết cách rotate credentials/key, isolate service và restore khi compromise.

Xem VPS self-managed

FAQ bảo mật n8n VPS

Có SSL là đủ chưa?

Chưa. Cần host firewall, SSH, identity, secrets, DB isolation và app controls.

PostgreSQL có nên public không?

Không nếu không có nhu cầu bắt buộc; baseline tốt là chỉ cho app/network nội bộ truy cập.

Community node có an toàn không?

Phải đánh giá như third-party code, không mặc định tin cậy.

Backup có cần mã hóa không?

Có nếu chứa dữ liệu nhạy cảm hoặc material giúp truy cập credentials.
