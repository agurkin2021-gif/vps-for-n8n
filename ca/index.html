COMPRA EL RECURS QUE UTILITZA ELS VOSTRE FLUX DE TREBALL

Què buscar en un n8n VPS

Prioritzeu RAM per a les dades de treball, CPU per al processament local i l'emmagatzematge de l'historial i els fitxers que conserveu. Incloeu la base de dades i qualsevol altra aplicació que comparteixi el VPS.

Estima el teu emmagatzematge de l'historial d'execució

Ús execucions desades per dia × mida mitjana emmagatzemada × dies de retenció. Per exemple: 1,000 execucions desades × 200 KB × 14 dies són aproximadament 2.8 GB de les dades d'execució emmagatzemades, utilitzant unitats decimals.

Afegiu espai per als índexs i registres de bases de dades, el sistema operatiu, els contenidors i els fitxers de flux de treball. Utilitzeu la vostra pròpia mida emmagatzemada observada en el càlcul. La retenció pot reduir la demanda d'emmagatzematge sense canviar CPU o RAM. Configuració de dades d'execució.

MemòriaDeixeu espai per a n8n, la base de dades i les dades que tenen les execucions superposades. Els fitxers grans i les transformacions canvien el requisit més que el nombre de fluxos de treball desats.
CPUCompreu més capacitat de processament per a un càlcul local sostingut. Compareu l'assignació de CPU així com el recompte de nuclis; les ofertes compartides i les dedicades són diferents.
EmmagatzematgeUtilitzeu l'emmagatzematge SSD o NVMe i trieu la capacitat de les dades que realment conservis. Posa les còpies de recuperació fora del servidor perquè sobrevisquin a la pèrdua del VPS.
Medi ambientTrieu Linux amb accés administratiu i suport Docker. Utilitzeu un nom d'amfitrió públic HTTPS per a webhooks i xarxes privades entre serveis d'aplicacions.
Xarxa i regióSi el vostre proveïdor ofereix diverses regions, col·loqueu el VPS a prop de les bases de dades, les API o els usuaris que dominen els viatges d'anada i tornada. Els fluxos de treball amb una gran quantitat de fitxers també fan que l'ample de banda i la política de transferència siguin part de la decisió dels recursos; La regió pot importar la residència de les dades.
Límit de suportAbans de pagar, verifiqueu què admet el proveïdor. Amb un VPS autogestionat, planifiqueu tenir actualitzacions, configuració i recuperació de n8n tret que s'inclogui explícitament la gestió a nivell d'aplicació.

PREGUNTES DE COMPRA RESPONDES

VPS per n8n: preguntes habituals

Quina configuració he de triar per a una petita empresa?

Trieu la configuració 2 vCPU, 4 GB RAM i 80 GB Standard per a una modesta pila de n8n i PostgreSQL que gestiona actualitzacions de CRM, clients potencials i petites integracions basades en JSON. Utilitzeu l'opció més gran per a treballs amb molta informació i superposició substancial; utilitzeu l'opció més lleugera per a una instància lleugera amb feines petites, majoritàriament seqüencials.

Quan és millor opció 8 GB RAM que 4 GB?

Quan els vostres fluxos de treball mantenen fitxers o conjunts de dades més grans a la memòria, realitzeu transformacions més pesades o executeu diversos treballs exigents junts. Un nombre elevat d'execucions mensuals per si sol no és un motiu per duplicar RAM; examinar les dades de treball i la superposició màxima.

Els fluxos de treball d'IA necessiten un GPU VPS?

Trucar un model allotjat API utilitza el maquinari d'inferència del proveïdor de models. Trieu el vostre n8n VPS per a l'orquestració, les càrregues útils i la concurrència. L'execució d'un model local o un servei d'inferència independent és una compra diferent amb el RAM i les necessitats de maquinari específiques del model.

Què passa després de triar un VPS?

Seleccioneu la configuració del servidor Standard i el sistema operatiu Linux al catàleg d'allotjament. Desplegueu n8n amb Docker, connecteu HTTPS i, a continuació, afegiu les vostres credencials de flux de treball. El camí de desplegament d'aquesta pàgina és autogestionat. Obriu la llista de verificació de configuració.

Puc moure els meus fluxos de treball existents a aquesta configuració?

Exporteu i importeu fluxos de treball, torneu a connectar les credencials quan sigui necessari i canvieu els webhooks i els activadors programats deliberadament. Per a un moviment d'instància completa, conserveu la base de dades i la clau de xifratge original perquè les credencials desades es puguin utilitzar. Preparació per a la migració i la recuperació.

Necessitaré Redis o un tauler de control de pagament?

Un desplegament normal de Docker d'una sola instància es pot executar sense Redis o un panell d'allotjament de pagament. Afegiu Redis amb el mode de cua quan necessiteu una execució basada en el treballador; trieu un panell només quan les seves funcions de gestió us siguin útils.

Com puc mantenir baixos els costos de n8n VPS sense reduir la mida del servidor?

Comenceu amb la configuració més petita que s'adapti a les vostres càrregues útils reals i a la superposició màxima, i després reduïu la demanda evitable abans d'actualitzar. Talleu l'historial d'execucions que no necessiteu, agrupa grans importacions, escaloneu les programacions pesades i utilitzeu les API d'IA allotjades quan no calgui inferència local. Mesureu la memòria, CPU i el disc durant el període més ocupat; pujar de nivell quan la càrrega de treball optimitzada encara arriba a límits sostinguts.
