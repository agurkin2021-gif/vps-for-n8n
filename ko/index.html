n8n 에 대한 VPS: 일반적인 질문

소규모 기업에서는 어떤 구성을 선택해야 합니까?

CRM 업데이트, 리드 및 소규모 JSON 기반 통합을 처리하는 적당한 n8n 및 PostgreSQL 스택을 위해 2 vCPU, 4 GB RAM 및 80 GB Standard 구성을 선택하십시오. 데이터가 많은 작업과 상당한 중복이 있는 경우에는 더 큰 옵션을 사용하십시오. 소규모의 순차적 작업이 포함된 린 인스턴스에는 더 가벼운 옵션을 사용하세요.

8 GB RAM 가 4 GB 보다 더 나은 선택은 언제입니까?

워크플로에서 더 큰 파일이나 데이터세트를 메모리에 보관하는 경우 더 무거운 변환을 수행하거나 여러 까다로운 작업을 함께 실행하세요. 높은 월간 실행 횟수만으로는 RAM 를 두 배로 늘릴 이유가 되지 않습니다. 작업 데이터와 피크 중첩을 조사합니다.

AI 워크플로에 GPU VPS 이 필요합니까?

호스팅 모델 API 을 호출하면 모델 공급자의 추론 하드웨어가 사용됩니다. 오케스트레이션, 페이로드 및 동시성을 위해 n8n VPS 를 선택하세요. 로컬 모델을 실행하거나 별도의 추론 서비스를 실행하는 것은 모델별 RAM 및 하드웨어 요구 사항에 따라 구매하는 것과 다릅니다.

VPS 을 선택한 후에는 어떻게 되나요?

호스팅 카탈로그에서 Standard 서버 구성과 Linux 운영 체제를 선택합니다. Docker 로 n8n 를 배포하고 HTTPS 를 연결한 다음 워크플로 자격 증명을 추가하세요. 이 페이지의 배포 경로는 자체 관리됩니다. 설정 체크리스트 열기.

기존 워크플로를 이 설정으로 이동할 수 있나요?

워크플로를 내보내고 가져오고, 필요한 경우 자격 증명을 다시 연결하고, 웹후크와 예약된 트리거를 의도적으로 전환하세요. 전체 인스턴스 이동의 경우 저장된 자격 증명을 계속 사용할 수 있도록 데이터베이스와 원래 암호화 키를 보존하세요. 마이그레이션 및 복구 준비.

Redis 또는 유료 제어판이 필요합니까?

일반 단일 인스턴스 Docker 배포는 Redis 또는 유료 호스팅 패널 없이 실행될 수 있습니다. 작업자 기반 실행이 필요한 경우 대기열 모드에 Redis 를 추가하세요. 관리 기능이 유용할 때만 패널을 선택하십시오.

서버 규모를 축소하지 않고도 n8n VPS 비용을 낮게 유지할 수 있는 방법은 무엇입니까?

실제 페이로드와 최대 중복에 맞는 가장 작은 구성으로 시작한 다음 업그레이드하기 전에 피할 수 있는 수요를 줄이세요. 필요하지 않은 실행 기록을 정리하고, 대규모 가져오기를 일괄 처리하고, 과중한 일정을 시차를 두고, 로컬 추론이 필요하지 않은 경우 호스팅된 AI API를 사용합니다. 가장 바쁜 기간 동안 메모리, CPU 및 디스크를 측정합니다. 최적화된 워크로드가 여전히 지속적인 한도에 도달하면 계층을 위로 이동합니다.
