মূল technical decision

Restore-যোগ্য backup

1

Database, N8N_ENCRYPTION_KEY, .n8n data এবং binary data একসাথে recovery set হিসেবে রাখুন।

2

Workflow/credential export full instance backup নয়; users, roles, history, variables ও settings বাদ যেতে পারে।

3

Restore-এর পর owner/project, ID collision এবং workflow activation state যাচাই করুন।

4

RPO/RTO নির্ধারণ করুন, off-server copy রাখুন এবং isolated restore drill করুন।

FAQ

Restore-যোগ্য backup: FAQ

1 GB কি বাস্তব VPS?

হ্যাঁ। এটি হালকা workload-এর জন্য বাস্তব entry VPS; সীমা হলো কম resource headroom।

2 GB কেন ভালো light baseline?

Docker, OS এবং ছোট peak-এর জন্য বেশি জায়গা থাকে।

Scale করার আগে কেন মাপবেন?

CPU, RAM, disk ও latency প্রকৃত bottleneck দেখায়।
