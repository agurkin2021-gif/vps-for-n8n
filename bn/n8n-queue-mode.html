মূল technical decision

Queue Mode সম্পূর্ণ পরিকল্পনা

1

Queue Mode PostgreSQL, Redis, main/webhook process এবং worker ব্যবহার করে; সব worker-এ একই N8N_ENCRYPTION_KEY লাগবে।

2

Main, webhook processor এবং worker একই n8n version-এ চলা উচিত।

3

Worker concurrency, queue depth ও latency মাপুন; slow DB বা external API শুধু worker বাড়িয়ে ঠিক হয় না।

4

Webhook processor আলাদা scaling layer; multi-main/HA সাধারণ Queue Mode-এর সমান নয়।
