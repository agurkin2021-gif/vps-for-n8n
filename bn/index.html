FAQ

n8n VPS-এর সাধারণ প্রশ্ন

n8n-এর জন্য কত RAM দরকার?

হালকা workload-এ 1–2 GB চলতে পারে। n8n + PostgreSQL সহ ছোট production-এর জন্য 4 GB practical baseline। Heavy data ও AI-তে 8 GB+ রাখুন।

n8n কি preinstalled থাকবে?

এই page self-install scenario ধরে। Provider স্পষ্টভাবে one-click n8n না বললে Docker/Compose দিয়ে install করতে হবে।

Execution-এর monthly limit আছে?

Ordinary VPS provider সাধারণত execution count করে না। Practical limit resources ও architecture দিয়ে নির্ধারিত হয়; n8n-এর paid edition-এর licensing আলাদা হতে পারে।

Domain কি দরকার?

Stable HTTPS URL এবং public webhook-এর জন্য domain বা subdomain ব্যবহার করা ভালো।

Redis কি দরকার?

Regular mode-এ নয়। Redis queue mode এবং workers-এর জন্য।

PostgreSQL আর n8n একই VPS-এ চলতে পারে?

হ্যাঁ, ছোট production-এ 4 GB RAM ও যথেষ্ট disk থাকলে practical। Load বাড়লে database আলাদা করা যায়।
