মূল technical decision

Host ও n8n hardening

1

HTTPS, restrictive firewall ও SSH key host সুরক্ষিত করে; PostgreSQL ও Redis private রাখুন।

2

MFA/2FA চালু করুন এবং editor/admin permission least privilege অনুযায়ী দিন।

3

অপ্রয়োজনীয় Public API ও high-risk node সীমিত করুন; community node-কে third-party code হিসেবে দেখুন।

4

SSRF protection এবং secret hygiene internal target access ও credential leak ঝুঁকি কমায়।
