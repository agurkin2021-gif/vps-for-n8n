ਮੁੱਖ technical decisions

Queue Mode architecture ਪੂਰੀ ਕਰੋ

1

Queue Mode PostgreSQL, Redis, main/webhook processes ਅਤੇ workers ਵਰਤਦਾ ਹੈ; ਸਭ workers ਵਿੱਚ ਇੱਕੋ N8N_ENCRYPTION_KEY ਹੋਵੇ।

2

Main, webhook processors ਅਤੇ workers ਇੱਕੋ n8n version ਚਲਾਉਣ।

3

Worker concurrency, queue depth ਅਤੇ latency ਮਾਪੋ; slow DB ਜਾਂ external API ਸਿਰਫ worker ਵਧਾਉਣ ਨਾਲ ਠੀਕ ਨਹੀਂ ਹੁੰਦੇ।

4

Webhook processors ਵੱਖਰੀ scaling layer ਹਨ; multi-main/HA ਆਮ Queue Mode ਦੇ ਬਰਾਬਰ ਨਹੀਂ।
