# Fresh official Ubuntu 22.04 / 24.04 / 26.04 installation
sudo apt update
sudo apt install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Register Docker's signed apt repository
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

ਇਹ ਅਧਿਕਾਰਤ Docker Ubuntu ਇੰਸਟਾਲੇਸ਼ਨ ਗਾਈਡ ਵਿੱਚ ਉਤਪਾਦਨ-ਮੁਖੀ ਭੰਡਾਰ ਵਿਧੀ ਹੈ। ਪਹਿਲਾਂ ਤੋਂ ਚੱਲ ਰਹੇ ਕੰਟੇਨਰਾਂ ਜਾਂ ਹੋਰ ਵੈਬਸਾਈਟਾਂ ਉੱਤੇ VPS ਉੱਤੇ Docker ਨੂੰ ਅੰਨ੍ਹੇਵਾਹ ਮੁਡ਼ ਸਥਾਪਤ ਜਾਂ ਨਾ ਹਟਾਓ।ਪਹਿਲਾਂ ਮੌਜੂਦਾ ਇੰਸਟਾਲੇਸ਼ਨ ਅਤੇ ਪੈਕੇਜ ਦੇ ਸੰਭਾਵਿਤ ਟਕਰਾਅ ਦਾ ਨਿਰੀਖਣ ਕਰੋ। ਡੈਬੀਅਨ ਜਾਂ ਕਿਸੇ ਹੋਰ ਵੰਡ ਲਈ, Ubuntu ਕਮਾਂਡਾਂ ਦੀ ਬਜਾਏ ਅਨੁਸਾਰੀ ਅਧਿਕਾਰਤ OS-ਵਿਸ਼ੇਸ਼ ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਵਰਤੋਂ ਕਰੋ।

ਇੱਕ ਫ਼ਾਇਰਵਾਲ ਨੂੰ ਸਮਰੱਥ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਆਪਣੀ ਅਸਲ SSH ਪ੍ਰਸ਼ਾਸਨ ਪੋਰਟ ਨੂੰ ਪਹੁੰਚਯੋਗ ਰੱਖੋ। ਸਰਟੀਫਿਕੇਟ ਜਾਰੀ ਕਰਨ ਅਤੇ ਸੰਪਾਦਕ ਲਈ ਅੰਦਰੂਨੀ HTTP (80) ਅਤੇ HTTPS (443) ਦੀ ਆਗਿਆ ਦਿਓ। Docker-ਪ੍ਰਕਾਸ਼ਿਤ ਕੰਟੇਨਰ ਪੋਰਟਾਂ ਕੁਝ ਯੂ. ਐੱਫ. ਡਬਲਿਊ ਨਿਯਮਾਂ ਨੂੰ ਨਜ਼ਰਅੰਦਾਜ਼ ਕਰ ਸਕਦੀਆਂ ਹਨ, ਇਸ ਲਈ Docker ਦੇ ਫ਼ਾਇਰਵਾਲ ਮਾਰਗਦਰਸ਼ਨ ਦੀ ਸਮੀਖਿਆ ਕਰੋ ਅਤੇ ਸਿਰਫ ਉਦੇਸ਼ਿਤ Caddy ਪੋਰਟਾਂ ਨੂੰ ਪ੍ਰਕਾਸ਼ਿਤ ਕਰੋ। ਇਹ ਕੰਪੋਜ਼ ਉਦਾਹਰਣ ਜਾਣਬੁੱਝ ਕੇ ਕਰਦੀ ਹੈ। ਨਹੀਂ। PostgreSQL (5432), n8n (5678) ਜਾਂ ਟਾਸਕ-ਰਨਰ ਬ੍ਰੋਕਰ (5679) ਨੂੰ ਜਨਤਕ ਇੰਟਰਨੈੱਟ ਉੱਤੇ ਪ੍ਰਕਾਸ਼ਿਤ ਕਰੋ।

2 ਵਾਤਾਵਰਣ ਮੁੱਲ ਬਣਾਓ ਅਤੇ ਕੁੰਜੀ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖੋ

ਪ੍ਰੋਜੈਕਟ ਡਾਇਰੈਕਟਰੀ ਵਿੱਚੋਂ, ਤਿੰਨ ਬਣਾਓ ਵੱਖਰਾ ਬੇਤਰਤੀਬੇ ਹੈਕਸਾਡੈਸੀਮਲ ਮੁੱਲਃ

openssl rand -hex 32

ਨਾਂ ਦੀ ਫਾਇਲ ਬਣਾਓ .env ਹੇਠਾਂ ਦਿੱਤੇ ਟੈਂਪਲੇਟ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹੋਏ, ਹਰੇਕ ਨੂੰ ਬਦਲੋ REPLACE_WITH_RANDOM_HEX ਇੱਕ ਵੱਖਰੇ ਪੈਦਾ ਕੀਤੇ ਮੁੱਲ ਦੇ ਨਾਲ, ਅਤੇ ਮੇਜ਼ਬਾਨ ਦਾ ਨਾਮ ਅਤੇ ਟਾਈਮਜ਼ੋਨ ਬਦਲੋ। 2.42.5 ਟੈਗ ਹੈ 8 ਅਕਤੂਬਰ 2026 ਉੱਤੇ ਸੂਚੀਬੱਧ ਸਥਿਰ ਰਿਲੀਜ਼, ਇੱਥੇ ਇੱਕ ਮਿਤੀ ਸੰਰਚਨਾ ਉਦਾਹਰਣ ਵਜੋਂ ਵਰਤਿਆ ਗਿਆ ਹੈ, ਲਾਈਵ-ਟੈਸਟ ਕੀਤੀ ਤਾਇਨਾਤੀ ਜਾਂ ਭਵਿੱਖ ਦੀ ਸੁਰੱਖਿਆ ਦੀ ਗਰੰਟੀ ਨਹੀਂਇੰਸਟਾਲ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ, ਮੌਜੂਦਾ ਅਧਿਕਾਰਤ n8n ਰੀਲੀਜ਼ਾਂ ਦੀ ਜਾਂਚ ਕਰੋ, ਫਿਰ n8n ਅਤੇ ਇਸ ਦੇ ਟਾਸਕ-ਰਨਰ ਚਿੱਤਰ ਨੂੰ ਉਸੇ ਤਸਦੀਕ ਕੀਤੇ ਸੰਸਕਰਣ ਉੱਤੇ ਰੱਖੋ।

4. HTTPS ਕੈਡੀ ਫਾਈਲ ਬਣਾਓ।

ਫਾਇਲ ਬਣਾਓ Caddyfile (ਪੂੰਜੀ C, ਕੋਈ ਵਿਸਤਾਰ ਨਹੀਂ) compose.yamlਉਦਾਹਰਣ ਹੋਸਟ ਨਾਮ ਨੂੰ ਹਰ ਜਗ੍ਹਾ ਆਪਣੇ DNS ਨਾਲ ਬਦਲੋਃ

n8n.example.com {
    reverse_proxy n8n:5678
}

Caddy ਜਨਤਾ ਨੂੰ ਬੇਨਤੀਆਂ ਅਤੇ ਨਵੀਨੀਕਰਨ TLS ਸਰਟੀਫਿਕੇਟ ਜਦੋਂ ਡੋਮੇਨ ਸਹੀ ਹੱਲ ਕਰਦਾ ਹੈ ਅਤੇ ਬਾਹਰੀ ਟ੍ਰੈਫਿਕ ਪੋਰਟਾਂ ਤੱਕ ਪਹੁੰਚ ਸਕਦਾ ਹੈ 80/443ਇਸ਼ਾਰਾ ਨਾ ਕਰੋ। DNS ਤੱਕ localhostਜੇ ਤੁਸੀਂ Caddy ਨੂੰ ਕਿਸੇ ਹੋਰ ਉਲਟ ਪ੍ਰੌਕਸੀ ਨਾਲ ਬਦਲਦੇ ਹੋ, ਤਾਂ ਅਸਲ ਹੋਸਟ, ਪ੍ਰੋਟੋਕੋਲ ਅਤੇ ਕਲਾਇੰਟ-ਐਡਰੈੱਸ ਹੈਡਰ ਨੂੰ ਅੱਗੇ ਵਧਾਓ ਅਤੇ ਐਡਜਸਟ ਕਰੋ। N8N_PROXY_HOPS ਭਰੋਸੇਯੋਗ ਪ੍ਰੌਕਸੀ ਹੌਪਸ ਦੀ ਅਸਲ ਗਿਣਤੀ ਲਈ।

5 ਡੱਬਿਆਂ ਨੂੰ ਸ਼ੁਰੂ ਕਰੋ ਅਤੇ ਬਾਹਰੋਂ ਟੈਸਟ ਕਰੋ।

ਸੰਭਾਲਣ ਤੋਂ ਬਾਅਦ ਪ੍ਰੋਜੈਕਟ ਡਾਇਰੈਕਟਰੀ ਤੋਂ ਇਹਨਾਂ ਕਮਾਂਡਾਂ ਨੂੰ ਚਲਾਓ .env, compose.yaml ਅਤੇ Caddyfile:

ਆਖਰੀ ਕਮਾਂਡ ਚੈੱਕ ਕਰਦੀ ਹੈ ਜਨਤਕ HTTPS ਸਿਹਤ ਅੰਤਮ ਬਿੰਦੂ। ਜੇ ਸਰਟੀਫਿਕੇਟ ਜਾਰੀ ਕਰਨਾ ਅਜੇ ਵੀ ਲੰਬਿਤ ਹੈ, ਤਾਂ n8n ਟੁੱਟਣ ਤੋਂ ਪਹਿਲਾਂ Caddy ਲੌਗ ਅਤੇ DNS/ਪੋਰਟਾਂ ਦੀ ਜਾਂਚ ਕਰੋ। https://n8n.example.comਪਹਿਲਾ ਮਾਲਕ ਖਾਤਾ ਤੁਰੰਤ ਬਣਾਓ ਅਤੇ ਢੁਕਵੀਂ ਸਾਈਨ-ਇਨ ਸੁਰੱਖਿਆ ਨੂੰ ਸਮਰੱਥ ਕਰੋ। ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਉਦਾਹਰਣ ਅਸਲ ਵਿੱਚ ਇੱਕ ਵਰਕਫਲੋ ਚਲਾਉਂਦਾ ਹੈ, ਨਾ ਕਿ ਸਿਰਫ ਸੰਪਾਦਕ ਲੋਡ ਕਰਦਾ ਹੈਃ

  1. ਸੰਪਾਦਕ ਵਿੱਚ, ਇੱਕ ਨਾਲ ਇੱਕ ਵਰਕਫਲੋ ਬਣਾਓ ਵੈਭੂਕ ਟਰਿੱਗਰ ਕਰੋ। ਸੈੱਟ ਕਰੋ HTTP ਵਿਧੀ ਤੱਕ GET, ਚੁਣੋ Path vps-check, ਅਤੇ ਸੈੱਟ ਕਰੋ ਜਵਾਬ ਦਿਓ। ਤੱਕ ਤੁਰੰਤਵਰਕਫਲੋ ਨੂੰ ਸੰਭਾਲੋ।
  2. ਕਲਿੱਕ ਕਰੋ ਟੈਸਟ ਈਵੈਂਟ ਲਈ ਸੁਣੋ, ਪੂਰੀ ਕਾਪੀ ਕਰੋ ਯੂ. ਆਰ. ਐੱਲ. ਦੀ ਜਾਂਚ ਕਰੋ n8n ਦੁਆਰਾ ਦਿਖਾਇਆ ਗਿਆ ਹੈ, ਅਤੇ ਕਿਸੇ ਹੋਰ ਜੰਤਰ ਤੋਂ ਚਲਾਇਆ ਗਿਆ ਹੈ curl -i 'PASTE_TEST_URL_HERE' ਕਾਪੀ ਕੀਤੇ ਯੂ. ਆਰ. ਐੱਲ. ਦੇ ਨਾਲ। HTTP ਸਫਲਤਾ ਪ੍ਰਤੀਕ੍ਰਿਆ ਅਤੇ ਆਉਣ ਵਾਲੇ ਈਵੈਂਟ ਦੇ n8n ਸੰਪਾਦਕ ਵਿੱਚ ਦਿਖਾਈ ਦੇਣ ਦੀ ਉਮੀਦ ਕਰੋ। ਟੈਸਟ ਯੂ. ਆਰ. ਐੱਲ. ਸਿਰਫ ਉਦੋਂ ਕੰਮ ਕਰਦੇ ਹਨ ਜਦੋਂ n8n ਇਵੈਂਟ ਲਈ ਸੁਣ ਰਿਹਾ ਹੁੰਦਾ ਹੈ।
  3. ਪ੍ਰਕਾਸ਼ਿਤ ਕਰੋ ਵਰਕਫਲੋ, ਨੋਡ ਨੂੰ ਇਸ ਵਿੱਚ ਬਦਲੋ ਉਤਪਾਦਨ ਯੂ. ਆਰ. ਐੱਲ., ਇਸ ਨੂੰ ਕਾਪੀ ਕਰੋ ਅਤੇ ਚਲਾਓ curl -i 'PASTE_PRODUCTION_URL_HERE' ਦੁਬਾਰਾ। ਵਰਕਫਲੋ ਦੇ ਹੇਠਾਂ ਲਾਗੂ ਕਰਨ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ। ਫਾਂਸੀਆਂ ਟੈਬ। ਪ੍ਰੋਡਕਸ਼ਨ ਵੈੱਬਹੁੱਕ ਬੇਨਤੀਆਂ ਲਈ ਵਰਕਫਲੋ ਪ੍ਰਕਾਸ਼ਿਤ ਕਰਨ ਦੀ ਜ਼ਰੂਰਤ ਹੁੰਦੀ ਹੈ ਅਤੇ ਸੰਪਾਦਕ ਦੇ ਟੈਸਟ ਵਿਊ ਵਿੱਚ ਆਪਣਾ ਪੇਲੋਡ ਨਹੀਂ ਦਿਖਾਉਂਦੇ।

ਇਹ ਇੱਕ ਜਾਣਬੁੱਝ ਕੇ ਸਧਾਰਨ, ਗੈਰ-ਪ੍ਰਮਾਣਿਕ ਧੂੰਆਂ ਟੈਸਟ ਹੈਃ ਇਸ ਨੂੰ ਕਦੇ ਵੀ ਗੁਪਤ ਨਾ ਭੇਜੋ। ਟੈਸਟਿੰਗ ਤੋਂ ਬਾਅਦ ਇਸ ਨੂੰ ਪ੍ਰਕਾਸ਼ਿਤ ਨਾ ਕਰੋ/ਹਟਾਓ, ਜਾਂ ਅਸਲ ਡੇਟਾ ਲਈ ਇੱਕ ਜਨਤਕ ਐਂਡਪੁਆਇੰਟ ਦੀ ਵਰਤੋਂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਵੈਭੂਕ ਪ੍ਰਮਾਣਿਕਤਾ/ਆਈਪੀ ਪਾਬੰਦੀਆਂ ਨੂੰ ਸੰਰਚਿਤ ਕਰੋ। ਅਧਿਕਾਰਤ ਵੈਭੂਕ ਟੈਸਟ/ਉਤਪਾਦਨ ਦਸਤਾਵੇਜ਼ ਦੇਖੋ।

6. ਪਿੰਨ ਕੀਤੇ ਸੰਸਕਰਣਾਂ ਨੂੰ ਬਦਲਣ ਤੋਂ ਪਹਿਲਾਂ ਬੈਕਅੱਪ ਕਰੋ

ਇੱਕ ਮੁਡ਼ ਪ੍ਰਾਪਤ ਕਰਨ ਯੋਗ PostgreSQL ਡੰਪ ਸੰਭਾਲੋ ਅਤੇ ਲਗਾਤਾਰ n8n ਡਾਟਾ ਵਾਲੀਅਮ, .env/ ਇੰਕ੍ਰਿਪਸ਼ਨ ਕੁੰਜੀ ਅਤੇ ਇਸ ਸਰਵਰ ਦੇ ਬਾਹਰ ਭੰਡਾਰਨ ਲਈ ਲੋਡ਼ੀਂਦੀਆਂ ਬਾਹਰੀ ਫਾਇਲਾਂ। ਇਸ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਇੱਕ ਰੀਸਟੋਰ ਦੀ ਤਸਦੀਕ ਕਰੋ ਬੈਕਅੱਪ ਅਤੇ ਰਿਕਵਰੀ ਗਾਈਡ ਉਤਪਾਦਨ ਨੂੰ ਅੱਪਡੇਟ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ। ਉਦਾਹਰਨ ਕਮਾਂਡਾਂਃ

# Back up the database, encryption key, instance data,

ਪਿੰਨ ਕਰੋ ਬਦਲੋ N8N_VERSION ਰਿਲੀਜ਼ ਨੋਟਸ ਨੂੰ ਪਡ਼੍ਹਨ ਤੋਂ ਬਾਅਦ ਹੀ; n8n ਅਤੇ ਦੌਡ਼ਾਕ ਚਿੱਤਰਾਂ ਦੋਵਾਂ ਨੂੰ ਇਕੱਠੇ ਅੱਗੇ ਵਧਣਾ ਚਾਹੀਦਾ ਹੈ। ਭੱਜੋ ਨਾ। docker compose down -v ਰੁਟੀਨ ਰੱਖ-ਰਖਾਅ ਦੇ ਦੌਰਾਨ ਕਿਉਂਕਿ ਉਹ ਨਾਮ ਦਿੱਤੇ ਡੇਟਾ ਵਾਲੀਅਮ ਨੂੰ ਹਟਾਉਂਦਾ ਹੈ. PostgreSQL ਪ੍ਰਮੁੱਖ-ਸੰਸਕਰਣ ਤਬਦੀਲੀਆਂ ਲਈ ਇੱਕ ਡਾਟਾਬੇਸ ਅਪਗ੍ਰੇਡ ਜਾਂ ਡੰਪ/ਰੀਸਟੋਰ ਯੋਜਨਾ ਦੀ ਜ਼ਰੂਰਤ ਹੁੰਦੀ ਹੈ; ਪੋਸਟਗ੍ਰੇਜ਼ 18 ਚਿੱਤਰ ਨੂੰ ਇੱਕ ਵੱਖਰੇ ਪ੍ਰਮੁੱਖ ਟੈਗ ਨਾਲ ਬਦਲਣਾ ਇੱਕ ਆਟੋਮੈਟਿਕ ਮਾਈਗ੍ਰੇਸ਼ਨ ਨਹੀਂ ਹੈ।

ਅਧਿਕਾਰਤ ਹਵਾਲੇਃ n8n Docker ਗਾਈਡ, n8n ਰਿਵਰਸ-ਪ੍ਰੌਕਸੀ/ਵੈਬਹੂਕ ਸੰਰਚਨਾ, ਅਤੇ ਅਧਿਕਾਰਤ PostgreSQL ਤਾਇਨਾਤੀ ਨੋਟਸ ਬਣਾਓ। ਕੋਈ ਬੁਨਿਆਦੀ ਢਾਂਚਾ ਬੈਂਚਮਾਰਕ ਜਾਂ ਪ੍ਰਦਾਤਾ-ਵਿਸ਼ੇਸ਼ ਪਹਿਲਾਂ ਤੋਂ ਸਥਾਪਤ ਵਿਸ਼ੇਸ਼ਤਾ ਨਹੀਂ ਮੰਨੀ ਜਾਂਦੀ।

ਗੁਪਤ ਅਤੇ ਜਨਤਕ ਯੂ. ਆਰ. ਐਲ. ਜਾਣਬੁੱਝ ਕੇ ਸੈੱਟ ਕਰੋ

ਉਤਪਾਦਨ ਪ੍ਰਮਾਣ ਪੱਤਰਾਂ ਨੂੰ ਸੰਭਾਲਣ ਤੋਂ ਪਹਿਲਾਂ ਇੱਕ ਮਜ਼ਬੂਤ n8n ਐਨਕ੍ਰਿਪਸ਼ਨ ਕੁੰਜੀ ਸੈੱਟ ਕਰੋ ਅਤੇ ਸੁਰੱਖਿਅਤ ਰੱਖੋ। ਰਿਕਵਰੀ ਤੋਂ ਬਾਅਦ ਉਹੀ ਕੁੰਜੀ ਦੀ ਲੋਡ਼ ਹੁੰਦੀ ਹੈ।

ਸਮਰਪਿਤ ਡਾਟਾਬੇਸ ਪ੍ਰਮਾਣ ਪੱਤਰਾਂ ਦੀ ਵਰਤੋਂ ਕਰੋ ਅਤੇ ਪਾਸਵਰਡਾਂ ਨੂੰ ਜਨਤਕ ਸਰੋਤ ਨਿਯੰਤਰਣ ਤੋਂ ਬਾਹਰ ਰੱਖੋ।

ਵੈਬੁੱਕ ਯੂ. ਆਰ. ਐੱਲ.

ਡਾਟਾਬੇਸ ਡਾਇਰੈਕਟਰੀ ਨੂੰ PostgreSQL ਕੰਟੇਨਰ ਤੋਂ ਸੁਤੰਤਰ ਤੌਰ ਉੱਤੇ ਜਾਰੀ ਰੱਖੋ।

ਹੋਸਟ ਭੰਡਾਰਨ ਨੂੰ ਬੇਲੋਡ਼ਾ ਆਗਿਆਯੋਗ ਬਣਾਏ ਬਿਨਾਂ ਲੋਡ਼ੀਂਦੇ ਕੰਟੇਨਰ ਉਪਭੋਗਤਾ ਦੁਆਰਾ ਲਿਖਣ ਯੋਗ ਮਾਊਂਟ ਕੀਤੇ ਮਾਰਗ ਬਣਾਓ।

ਵਰਕਫਲੋ ਫਾਇਲਾਂ

ਕਿਸੇ ਵੀ ਮਾਊਂਟ ਕੀਤੀਆਂ ਫਾਈਲਾਂ ਜਾਂ ਬਾਈਨਰੀ-ਡੇਟਾ ਸਟੋਰੇਜ ਨੂੰ ਜਾਰੀ ਰੱਖੋ ਜਿਸ ਉੱਤੇ ਉਤਪਾਦਨ ਵਰਕਫਲੋ ਨਿਰਭਰ ਕਰਦਾ ਹੈ।

PostgreSQL

n8n ਨੂੰ ਪ੍ਰਾਈਵੇਟ ਡਾਟਾਬੇਸ ਸੇਵਾ ਨਾਲ ਜੋਡ਼ੋ

ਡਾਟਾਬੇਸ ਕਿਸਮਗਲਤੀ ਨਾਲ SQLite ਉੱਤੇ ਵਾਪਸ ਆਉਣ ਦੀ ਬਜਾਏ PostgreSQL ਲਈ n8n ਦੀ ਸੰਰਚਨਾ ਕਰੋ।
ਮੇਜ਼ਬਾਨਪ੍ਰਾਈਵੇਟ Docker ਨੈੱਟਵਰਕ ਉੱਤੇ PostgreSQL ਸੇਵਾ ਨਾਮ ਦੀ ਵਰਤੋਂ ਕਰੋ।
ਪ੍ਰਮਾਣ ਪੱਤਰਲੋਡ਼ੀਂਦੇ ਡਾਟਾਬੇਸ, ਐਪਲੀਕੇਸ਼ਨ ਉਪਭੋਗਤਾ ਅਤੇ ਪਾਸਵਰਡ ਨਾਲ ਮੇਲ ਕਰੋ।
