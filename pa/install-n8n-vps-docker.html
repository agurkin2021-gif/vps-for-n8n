ਮੁੱਖ technical decisions

Production ਤੋਂ ਪਹਿਲਾਂ deployment verify ਕਰੋ

1

Docker Compose ਵਿੱਚ n8n ਅਤੇ PostgreSQL persistent volumes ਵਰਤਣ; PostgreSQL ਨੂੰ public internet ਉੱਤੇ expose ਨਾ ਕਰੋ।

2

3

Start ਤੋਂ ਬਾਅਦ docker compose ps, logs ਅਤੇ /healthz check ਕਰਕੇ ਹੀ production webhooks enable ਕਰੋ।

4

n8n version pin ਕਰੋ; PostgreSQL major version ਨੂੰ ਉਸੇ volume ਉੱਤੇ blind upgrade ਨਾ ਕਰੋ।
