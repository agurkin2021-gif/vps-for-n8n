ਮੁੱਖ technical decisions

Production sizing ਪੂਰਾ ਕਰੋ

1

1 GB ਬਹੁਤ ਹਲਕੇ workload ਲਈ ਇੱਕ ਅਸਲੀ entry VPS ਹੈ; 2 GB Docker ਅਤੇ ਛੋਟੇ peaks ਲਈ ਵੱਧ headroom ਦਿੰਦਾ ਹੈ।

2

Server size workflow count ਨਾਲ ਨਹੀਂ, concurrent executions, payload size, duration ਅਤੇ CPU-heavy nodes ਨਾਲ ਚੁਣੋ।

3

PostgreSQL, reverse proxy, monitoring, logs ਅਤੇ OS ਵੀ ਉਹੀ RAM/CPU budget ਵਰਤਦੇ ਹਨ।

4

ਹਲਕੇ workload ਲਈ SSD ਕਾਫ਼ੀ ਹੈ; PostgreSQL/history I/O bottleneck ਹੋਵੇ ਤਾਂ NVMe ਲਾਭਦਾਇਕ ਹੈ।
