मुख्य technical decisions

Restore होणारा backup

1

Database, N8N_ENCRYPTION_KEY, .n8n data आणि binary data एक recovery set म्हणून backup करा.

2

Workflow/credential export हा full instance backup नाही; users, roles, history, variables आणि settings राहू शकतात.

3

Restore वेळी owner/project, ID collisions आणि workflow activation state तपासा.

4

RPO/RTO ठरवा, off-server copy ठेवा आणि isolated restore drill करा.

Restore होणारा backup: FAQ

1 GB हा खरा VPS आहे का?

हो. तो हलक्या workload साठी खरा entry VPS आहे; मर्यादा कमी resource headroom आहे.

2 GB light baseline का?

Docker, OS आणि लहान peaks साठी अधिक headroom मिळतो.

Scale आधी measure का?

CPU, RAM, disk आणि latency खरा bottleneck दाखवतात.
