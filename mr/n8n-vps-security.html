मुख्य technical decisions

Host आणि n8n harden करा

1

HTTPS, restrictive firewall आणि SSH keys host सुरक्षित करतात; PostgreSQL आणि Redis private ठेवा.

2

MFA/2FA enable करा आणि editor/admin अधिकार least privilege वर ठेवा.

3

Unused Public API आणि high-risk nodes मर्यादित करा; community nodes third-party code म्हणून माना.

4

SSRF protection आणि secret hygiene internal targets व credential leaks चा धोका कमी करतात.

1 GB हा खरा VPS आहे का?

हो. तो हलक्या workload साठी खरा entry VPS आहे; मर्यादा कमी resource headroom आहे.

2 GB light baseline का?

Docker, OS आणि लहान peaks साठी अधिक headroom मिळतो.

CPU, RAM, disk आणि latency खरा bottleneck दाखवतात.
