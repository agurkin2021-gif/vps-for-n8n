डेटाबेस आणि Redis

बॅकएंड सेवा खाजगी ठेवा

विशिष्ट Docker रचना रचनेत, PostgreSQL आणि कतार-मोड Redis हे यजमान-प्रकाशित बंदरांद्वारे नव्हे तर खाजगी नेटवर्किंगद्वारे संबंधित कंटेनरद्वारे पोहोचण्यायोग्य असले पाहिजे. docker compose ps की 5432 आणि 6379 सार्वजनिकरित्या प्रकाशित केलेले नाहीत; VPS/क्लाउड फायरवॉल एक्सपोजरचे स्वतंत्रपणे पुनरावलोकन करा. नेटवर्क धोरणे किमान-विशेषाधिकार डेटाबेस क्रेडेन्शियल्सची जागा घेत नाहीत.
