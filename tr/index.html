HAZIR KURULUM VS SELF-MANAGED

Türkçe SERP’te kurulum modeli satın alma kararının parçası

Hazır kurulu / tek tık

Netlen ve Hostinger gibi teklifler kurulum süresini azaltır. Ancak tek tık kurulum, sürekli yönetilen hizmet anlamına gelmez.

Self-managed VPS

Root, Docker, PostgreSQL, reverse proxy, custom node ve queue mode üzerinde daha fazla kontrol.

Managed hizmet

Kurulum, güncelleme, yedekleme, monitoring ve destek kapsamı ayrı ayrı doğrulanmalı.

Bu sayfanın varsayımı

Standart self-hosted VPS esas alınır. Sağlayıcı açıkça belirtmiyorsa VDSina için hazır kurulu n8n, otomatik yedek veya managed n8n iddiası yapılmaz.

EXECUTION, CONCURRENCY & QUEUE MODE

“Sınırsız workflow” ile “sınırsız kapasite” aynı şey değildir

Execution sayacı

Standart VPS genellikle n8n execution sayısına göre ücretlendirme yapmaz.

Concurrency

Gerçek kapasite CPU, RAM, PostgreSQL, disk I/O ve aynı anda çalışan workflow’lara bağlıdır.

Queue mode

Yük büyüdüğünde Redis + worker yapısı concurrency’yi dağıtabilir; her kurulumda gerekli değildir.

License sınırı

Community ile Business/Enterprise aynı özellik seti değildir. VPS satın almak ücretli n8n özelliklerini otomatik açmaz.

n8n VPS hakkında sık sorulanlar

n8n için ne kadar RAM gerekir?

Test ve hafif kullanım için 1–2 GB yeterli olabilir. n8n + PostgreSQL küçük production için 4 GB daha pratik bir tabandır. Ağır/AI için 8 GB+ düşünün.

n8n hazır kurulu gelir mi?

Yalnızca sağlayıcı bunu açıkça söylüyorsa. Aksi halde Docker/Compose ile sizin kurmanız gerekir.

VPS üzerinde aylık execution limiti var mı?

Standart VPS genellikle execution sayısını saymaz; pratik limit kaynaklar ve mimaridir.

Türkiye lokasyonu şart mı?

Hayır. Kullanıcılarınız, API hedefleriniz, veri politikası ve gerçek latency ihtiyacınıza göre karar verin.

Queue mode ne zaman gerekir?

Tek process sınırına yaklaşıldığında veya concurrency’yi worker’lara dağıtmak gerektiğinde.

AI agent için GPU gerekir mi?

Harici LLM API kullanıyorsanız genellikle gerekmez. Local model inference yaparsanız gereksinim tamamen değişir.
